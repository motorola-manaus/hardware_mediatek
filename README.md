# MediaTek Hardware Interfaces (`hardware_mediatek`)

This repository contains common hardware HAL implementations, AIDL interfaces, and build definitions for MediaTek platforms, tailored for Motorola MT6879 devices.

## Directory Path in Source Tree

```bash
hardware/mediatek
```

## How to Clone

```bash
git clone https://github.com/motorola-manaus/hardware_mediatek.git -b seventeen hardware/mediatek
```
